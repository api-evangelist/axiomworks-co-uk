Axiom Works AgentReader provides pay‑per‑call tools for AI agents, enabling on‑demand lookups of UK Companies House records, KYB data, SEC EDGAR filings, EU VAT information, web‑to‑markdown conversion, and EVM on‑chain queries. Access is granted via the x402 HTTP 402 payment model using USDC on Base, with no API keys required. The service supports HTTP and MCP transports, delivering concise data for autonomous workflows.

**Areas:** API · Company Data · KYB · Due Diligence · Domain Health · Pay‑per‑call
